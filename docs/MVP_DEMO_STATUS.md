This file records the showcase boundary. It is not the product authority and it is not a statement
that the V3 product is an MVP. The active authority remains
`J_A_AUTOMATION_UNIFIED_SPEC_V3_LIGHTWEIGHT_2026-08-18.md`; current implementation evidence is in
`V3_IMPLEMENTATION_PROGRESS.md` and `V3_DOD_EVIDENCE.md`.

`owner_admin` using `antonny.luty@j-aautomation.com`, plus synthetic finance, project-manager and
worker accounts. It creates clients, contacts, projects, schedules, skills, availability, assignments,
actual/pending time, daily and technical reports, technical changes, private receipt PDFs, hotel and
airfare travel evidence, expenses, planning records, rates, legal/tax configuration, draft labor,
expense and milestone invoice streams, closed periods, period reports, an Accounting Pack draft and
a project closeout draft while preserving the V3 data boundaries.

Synthetic seed records are test data and must never be promoted to production or committed as a
database, upload, invoice or financial artifact. Use [SHOWCASE_ACCESS.md](SHOWCASE_ACCESS.md) for
the access sheet and the explicit demo-mode warning.
