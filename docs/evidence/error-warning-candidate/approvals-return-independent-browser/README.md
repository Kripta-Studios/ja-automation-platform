# Independent approvals and return browser discovery

Actual headless Chromium against a **separate disposable candidate preview built from `a2b1e9a`** on 27 September 2026. The preview was built before the subsequent Approval action precision patch. Owner created an Active synthetic project with a Manager through New Project, assigned a Worker through Assign worker, and the Worker created and submitted three time entries and two expenses through the rendered forms. All ten create/submit requests returned HTTP 200. This run used no production accounts, records, or deployment.
