# Independent Billing browser QA

Date: 2026-09-27. Candidate: isolated branch at base `103eaf5` with the uncommitted Billing overlay. These checks used actual Chromium through Playwright MCP against a fresh disposable candidate database. They do not describe production behavior. Screenshots crop only warning notices and contain no account credentials or record IDs.

The Finance **Review invoice** destination is a product defect found independently of the automated suite. Other checked outcomes passed. The browser console showed an unrelated HTTP 503 from `/api/offline/identity` (offline mode disabled in this fixture); no Billing form JavaScript exception was observed. No screenshots or traces contain passwords, session tokens, or full request bodies.

Evidence: `results.json`, `archive-phone-pt.png`, `finance-linked-phone-en.png`, `historical-phone-en.png`.

## Selected-invoice remedy recheck after fix

The list-only Review invoice destination above is the **pre-fix finding**. On a rebuilt candidate with the selected-detail remedy, a fresh disposable Chromium run clicked the link for Finance at 390 px in EN/ES/PT and Owner at 1440 px in PT. All 4 cases opened the exact selected invoice detail (HTTP 200); invoice state, version, number, and issue timestamp stayed unchanged, and no page exceptions occurred. The destination preserves the selected record by URL instead of returning to the list and losing the search context. [Reduced post-fix result](post-fix-results.json) contains no invoice IDs, account data, request bodies, or secrets.
