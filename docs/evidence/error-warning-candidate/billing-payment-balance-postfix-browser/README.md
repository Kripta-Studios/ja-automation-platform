The disposable preview produced known offline identity 503 responses on navigation; the expected native stale payment POST returned 409.

The reproducible case is [`postfix.spec.ts`](postfix.spec.ts) with [`playwright.config.ts`](playwright.config.ts): Chromium **1/1 passed**. The fixture pointer and lock were removed and port 4174 had no listener after the run. The separate delayed enhanced response while switching to a _different_ invoice was not exercised: this deterministic fixture supplied one usable issued invoice, and creating another would require an unrelated invoice readiness workflow. The UI contains a reviewed selection guard, but this browser result does not certify that race; it covers only the two stale-balance races above.
