The disposable preview produced known offline identity 503 responses on navigation, plus the expected native 409 and 400 action responses.

The retained problem still reopened the invoice drawer, and the hard reload remedy restored `view=invoices&invoice=<record>#invoice-collections` with a fresh maximum. The remedy URL did not include an explicit `lang` parameter; the app also persists locale in a cookie, so this trace does not establish a language reset. The optional Owner 1440 Portuguese/Spanish invalid reversal, zero-remaining recovery after a full reversal, and two-role idempotency race were not browser exercised in this focused run.
