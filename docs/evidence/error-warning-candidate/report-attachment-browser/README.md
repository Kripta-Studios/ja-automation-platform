The same journey passed at 390 × 844 and 1440 × 900. A disposable project had a real manager membership, worker assignment, and draft daily report. Browser sessions used the seeded Worker, Project Manager, and Finance roles.

| Case                         | Browser and network observation                                                                                                                                                                                                                                                                                                          |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Worker upload                | Real form POST returned 201, reload displayed the private file, one link persisted.                                                                                                                                                                                                                                                      |
| Manager upload               | Manager session used the same assigned project; POST returned 201 and the second private file appeared.                                                                                                                                                                                                                                  |
| Committed file cancellation  | Authenticated browser request to the cancel route returned typed 409 `REPORT_ATTACHMENT_IMMUTABLE`; both links remained. The UI correctly has no cancel button for a committed file.                                                                                                                                                     |
| Duplicate content            | Reuploading the exact worker file returned typed 409 `REPORT_ATTACHMENT_DUPLICATE_CONTENT`; the notice said no new attachment was saved, offered a review link, retained notes, and the link count stayed at two.                                                                                                                        |
| Invalid file                 | A `.pdf` whose bytes were not a PDF returned typed 400 `REPORT_ATTACHMENT_FILE_INVALID`; the form retained filename and notes.                                                                                                                                                                                                           |
| Report changed after opening | Advancing the disposable report version after opening the form returned typed 409 `REPORT_ATTACHMENT_STALE_VERSION`; filename and notes remained, and the remedy opened the current report in another tab.                                                                                                                               |
| Finance role                 | The report detail withheld the upload form (or withheld the page); an authenticated browser POST returned typed 403 `REPORT_ATTACHMENT_ACCESS_REQUIRED`; no link was added.                                                                                                                                                              |
| Lost upload response         | The browser intercepted a real successful POST then discarded its response. The inline notice explained that success is uncertain and directed the worker to review attachments in another tab. File, type, and notes remained; only one POST occurred, the new file appeared in the review tab, and the persisted link count was three. |

For each visible failure, the inline alert received keyboard focus, stayed fully inside the viewport, and retained a scroll position above 100 px. The typed response checks covered code, message key where applicable, correlation ID, field errors, and remedies. Browser page errors and unexpected console errors were empty; the deliberately aborted request may emit a browser resource error.

The eight PNGs in this folder crop only the disposable problem notice. The matching JSON files are redacted response and viewport metadata; they contain no credentials, report IDs, file contents, or raw network payloads. The test file is the replayable trace of the exact clicks, response assertions, role sessions, and database invariants. Passing Playwright traces were not retained because the runner is configured to keep traces on failure only.
