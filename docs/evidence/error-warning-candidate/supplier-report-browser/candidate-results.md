For all three reversed-date cases, the report form kept the selected synthetic project, `from=2026-09-28`, `to=2026-09-27`, and language; the end-date field showed a localized inline error. The problem notice received keyboard focus and was fully inside the viewport after the navigation timer. No horizontal overflow or JavaScript console exception was observed. The form started at scroll position 0 in these views; a nonzero form-scroll restoration case was not exercised. Cropped evidence: [`owner-390-en-period.png`](./owner-390-en-period.png), [`supplier_coordinator-1440-es-period.png`](./supplier_coordinator-1440-es-period.png), [`external_technician-390-pt-period.png`](./external_technician-390-pt-period.png).

**Actual CSV network:** a valid Owner request downloaded a `text/csv` attachment successfully. Malformed date and missing project returned structured `application/problem+json` HTTP 400 with `SUPPLIER_REPORT_PERIOD_DATE_INVALID` and `SUPPLIER_REPORT_PROJECT_REQUIRED`; signed-out request returned 401 `SUPPLIER_REPORT_SIGN_IN_REQUIRED`; Project Manager returned 403 `SUPPLIER_REPORT_ROLE_REQUIRED`. After the synthetic project was changed to Closing in the disposable database, the still-open Owner report’s Download CSV request returned 404 `SUPPLIER_REPORT_PROJECT_UNAVAILABLE`. The existing page showed its role-appropriate notice, preserved the project selection, focused the notice, and kept it visible at 390 px. Reloading the deep link kept the unavailable project selected and showed Closing and Review project status. A Supplier Coordinator deep link showed 200 with `SUPPLIER_REPORT_PROJECT_SCOPE_CHANGED`, focused the notice, and did not reveal the project name.

**Simulated transport cases:** Playwright intercepted only the CSV fetch for one 409 `SUPPLIER_REPORT_PROJECT_SCOPE_CHANGED` and one 503 `SUPPLIER_REPORT_SERVICE_UNAVAILABLE` response, each with the exact typed problem contract. The UI displayed the localized cause and permitted remedy, focused the notice, and kept it visible without overflow. The 503 copy said no data was changed, supplied a reference ID, and offered Try CSV download again. These interceptions verify UI handling; they do **not** prove that normal server conditions emitted a 409 or 503 during this run. Cropped 503 evidence: [`owner-390-en-simulated-503.png`](./owner-390-en-simulated-503.png).

**Result:** one Playwright browser test passed. The candidate closes the production reversed-date full-page generic error and empty-range wording gap for the roles and languages checked.
