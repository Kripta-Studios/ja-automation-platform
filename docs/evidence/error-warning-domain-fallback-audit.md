# Domain error mapping review candidates

Current literal-source recount (2026-09-27): 610 translated code/message pairs, 442 explicit remedy pairs, and 342 narrowly state-specific codes. Older figures in the chronological audit below describe the candidate at the time of each review.

Run `node scripts/error-warning-audit/find-domain-error-review-candidates.cjs` from the repository root. The 2026-09-27 candidate scan found 362 literal `ValidationError`, `ConflictError`, or `AccessDeniedError` throws in database domain files, representing 291 distinct type/message pairs. After the current mappings, 105 pairs have no exact text in portal source.

This is a **review queue, not a failure count**. A route may map an error by code or regular expression, prevalidation may prevent the throw from being reached, and some errors belong to API downloads rather than form actions. Conversely, a string appearing in portal source does not prove the user sees a precise explanation. The release gate still requires runtime and browser evidence for known cases.
