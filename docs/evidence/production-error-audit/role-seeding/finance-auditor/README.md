## Dependency for full Finance journey

The live Billing form cannot create a stream or draft until an active issuing legal entity is available for the selected project currency. Creating a fake issuer would affect global finance configuration, so this QA pass stopped at the missing-configuration failure. A later isolated or explicitly designated QA issuer and approved source records are required for draft-invoice success and state-conflict browser cases. The Finance role cannot grant the initial worker memberships for the new project; the owner must do that through the normal UI.
