## Enter a week and submit eligible drafts

Go here: Time → Enter a week in a table; Submit this week

Context: Reference procedure · current controls/source checked; mutations not exercised in this role lab

The weekly table is a faster entry tool for your own actual daily work. Blank days are skipped. Planned hours remain separate. Review existing rows first so a second table save does not duplicate a day already entered.

Copy previous week layout copies layout with zero hours. It does not assert that last week’s work happened again. Submit all week drafts handles eligible drafts for your own selected week. A linked correction may appear in the draft count; do not assume weekly submission universally excludes corrections. ### Verify the result

- Draft is distinct from Submitted. A zero-hour copied layout is incomplete until actual work is entered.

### If you get stuck
