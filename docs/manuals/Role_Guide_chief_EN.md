# Chief / delegated team lead: current crew guide

**Deployed edition, 24 September 2026.** See the [full current guide](Current_Deployed_Workflows_2026-09-24.md) and [role-flow diagram](Role_Workflows.pdf). The tablet screenshot below is from the actual deployed app with a Supplier Coordinator test account, without an active project delegation.

1. Ask Owner to assign you as chief for the correct project, effective dates and workers. **Crew hours** does not grant itself access merely because your account has a team-lead title.
2. Open **Crew hours**, choose the project and work date, and select **Show project**. Verify that every listed worker really worked on that project/date.
3. Select one worker for an individual entry, or multiple workers for the team. Use **shared hours** only if every selected worker actually worked the same duration; use **individual hours** for different durations. Check each row before submitting. The saved time belongs to the actual worker and is attributed to you as submitter.
4. For a shared receipt, record **one** real expense and use **Allocate one crew receipt** to split its amount. Do not duplicate a receipt across workers. Each time and expense entry follows its own normal review; chief access grants neither another person's pay visibility nor automatic approval.
