# Worker: current time, expense and report guide

**Deployed edition, 24 September 2026.** See the [full current guide](Current_Deployed_Workflows_2026-09-24.md) and [role-flow diagram](Role_Workflows.pdf). The following phone screenshots came from the actual deployed app using an existing Worker test account.

1. Open **Time → Log time**. Select an **assigned project** and true work date. Enter **Actual hours** (for example `7.5` means 7 h 30 min); use **Add start and end times** only when the real interval is known. Select the category and describe the activity. Save a draft or submit accurate work for approval. Do not substitute planned hours for work done.
2. Open **Expenses → Record expense**. Attach a valid receipt, select the assigned project, actual date, category, amount and real payer. **Time expense occurred** is optional. If the same expense belongs to a shift, use the offered linked-entry flow. Expense reimbursement and customer billing are separate project-person rules.
3. In **Reports**, submit factual Daily or Technical / PLC work with the correct project and date. An internal review does not sign for the customer.
4. Check your own status and **My Pay** only. Draft, submitted, approved, scheduled, finalized and paid mean different things. A payment plan is not a bank transfer.
