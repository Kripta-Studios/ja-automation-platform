Set up the work
1Owner

Create client

  • Confirm client details, contacts and billing address.
  • Choose the correct currency and site context.
Handoff: a client record available for a new project.
2Owner · accountant input

Prepare issuing authority

  • Set the legal issuer and tax profile for the project currency.
  • Use an approved invoice-number policy before issuing.
Handoff: valid issuer/tax/numbering configuration.
3Owner · project manager

Create project

  • Set client, name and required cost-center code.
  • Choose manager, timezone and model; add alias, budget or planned end if useful.
Handoff: saved project with stable identity.
4Owner · project manager

Assign the people

  • Find workers by expertise; set dated project assignments.
  • Owner grants a chief specific project-member scope when team entry is needed.
Handoff: each person can work in the right project and dates.
People + project context → commercial readiness → actual work
Configure and record
5Owner · Finance

Set terms per person

  • Set customer hourly charge separately from worker compensation.
  • Choose who pays each expense, worker reimbursement and customer recovery.
  • Check effective dates and missing-rate warnings.
6Owner · Finance

Set project billing

  • In Project → Billing setup, choose model, cadence, tax and issuer.
  • Choose one invoice with labor/expense sections or two separate invoices.
  • Review the calculation summary; save a reusable template if useful.
7Worker · delegated crew chief

Record actual work

WorkerEnter own dated hours or interval, activity, report and expense with payer, receipt and occurrence time.
Crew chiefEnter each delegated member's hours/activity; copy shared values, then check every person's row.
The worker is the subject; the chief remains the recorded submitter.
8Worker · crew chief

Submit the records

  • Verify actual hours and expenses, then submit them for review.
  • A shared receipt is one expense or explicit allocations, never repeated for each worker.
Handoff: submitted source records; no invoice or payment yet.
Project settings and forecasts do not create worked hours. A chief can enter only for explicitly delegated people and cannot approve their own team submissions.

Validate the source of every amount
9Authorized approver

Review actual records

  • Check the assigned person, date, hours, activity, report and receipt.
  • Approve or return with a reason; a returned record goes back for correction.
Only approved, eligible sources proceed.
10Finance

Classify and explain

  • Confirm billable time and each expense's reimbursement and customer treatment.
  • Review hours, selected rates, exclusions and totals in the project calculation.
Missing terms block final finance actions; never assume zero.
11Project manager · customer

Report and sign off

  • Generate an operational report from approved time/activity.
  • Complete customer sign-off only when the project requires it.
A generated report is not itself customer acceptance.
12Finance · Owner

Prepare invoice draft

  • Select the project and period; include approved, eligible, unbilled sources.
  • Preview lines, labor/expense sections, tax, recipient and PDF.
One combined invoice or separate labor/expense drafts follows project setup.
Reviewed draft + valid issuer and numbering → immutable invoice → collection
Issue, deliver and reconcile
13Authorized issuer

Issue invoice

  • Recheck source reservation, exact totals, tax and approved numbering policy.
  • Issue once; the numbered invoice is a historical snapshot.
Corrections use void, credit or replacement, not silent edits.
14Finance

Deliver and follow up

  • Use the authorized email/delivery action and inspect its state.
  • Track due date and follow-up separately from the issued document.
Queued/sent is not proof the recipient received or accepted it.
15Finance

Record actual payment

  • Use real bank/payment evidence, date, amount, currency and reference.
  • Record partial payments against the remaining balance.
Expected collection is only a forecast, not cash.
16Finance · Owner

Reconcile and close

  • Reconcile invoice, collections, expenses and project reports.
  • Separately finalize worker compensation and record actual worker pay.
Keep audit trail and issued history; archive only through the proper workflow.
Role boundaries: workers see their own pay; chiefs and project managers do not gain coworkers' private compensation. Customer reports contain operational work, not internal rates. A test or preview does not prove a live invoice was issued, delivered or paid.
