Daily work and review

1. Owner

Set up access

Create the project; verify site timezone, team dates and required permissions. Publish plans separately from actual work.

2. Worker / external technician

Capture actual facts

Digital workers → Open work capture → Review facts → Create server drafts. Add original evidence and submit each record.

3. Crew chief / supplier coordinator

Record authorized team work

Use Crew hours or Supplier team for delegated entries. Work capture creates own records only. Coordinator uses the supplier workspace.

4. Authorized reviewer

Review original records

PM needs a current review grant. Supplier time goes to Owner. Accepting a follow-up does not approve time, expenses or reports.

Go to section (Ctrl/⌘ Shift K) finds authorized actions, configuration and sections. Find a task (Ctrl/⌘ K) is separate and only opens an allowed destination. Record search appears as a separate handoff only when enabled. At 200% text, forms reflow naturally; use visible labels and error-summary field links. Time, Daily report and Expense drafts remain separate sources.

Project to invoice

1. Owner / Finance

Resolve prerequisites

Owner time/expense approval includes financial acceptance; PM approval still needs Finance review. Check classification, dated terms, issuer, tax and evidence.

2. Owner / Finance

Choose invoice scope

Choose eligible selected records or the complete configured period. Filters never change selection. Review visible/selected counts and source reservations.

3. Owner / Finance

Optional digital case

Digital workers → Apply filters → Open case → inspect snapshot → record current review → Create invoice draft. Refresh/review again after source changes.

4. Owner / Finance

Issue and collect

Review the draft, approve and issue through invoice controls. Wait for Ready final PDF; send deliberately. Record collection only with genuine payment evidence.

The whole-period composer has three stages and all 12 details, with nine direct shortcuts. Whole-period totals cover the full period, never a selected subset. Selected-stream edits preserve project, mode, dates and source references, then revalidate. A saved draft is not issued or sent; queued/running is not Ready. Tax, cadence and commercial changes use effective-dated successor conditions.

J&A Automation · Current workflow reference · 17 October 2026

Follow-ups, automation and audit

1. PM / permitted coordinator

Assign the next step

Create Scope change, Handover or Evidence follow-up with project, eligible owner, due date and authorized evidence references. Supplier Coordinator uses its separate workspace.

2. Assigned internal worker

Report progress

Open → In progress → Ready for review. Update factual evidence. External technicians do not receive internal follow-up controls.

3. Authorized reviewer

Decide from evidence

Check current / claimed / missing / stale references. Handover acceptance needs current supporting evidence; waiver needs a reason. Preserve terminal decisions.

4. Auditor

Inspect and report

Read cases, source versions, review reasons, invoice links and Accounting artifacts. Hand findings to Owner/Finance; no mutation or new approval.

Due follow-ups create one in-app notification per current owner/deadline. OCR and supported on-device dictation aid text entry only. Policy proposals never apply settings automatically.
