# Project defaults and individual worker agreements

Owners can configure customer rates, internal costs, worker compensation and expense terms for each project assignment. Finance can maintain financial terms within its authorized scope.

## Create a project

1. Choose the client and fill in the project details.
2. Open **Project defaults for people (optional)** and enable defaults if needed. Enter the effective date, rates, compensation method and expense terms.
3. Open **Worker assignments (optional)**. Add each worker and their assignment dates.
4. Choose **Use project defaults** or **Override for this person** for each row. Individual rows can have different rates, pay methods, reimbursement and customer expense recovery.
5. Save the project. The project, assignments and initial agreements are saved together. Correct highlighted errors using the retained values.

Both optional sections can remain empty. Workers can be assigned later.

## Change an existing worker agreement

Open the project's **Team** tab, then **Configure person rates**. In **Billing → Review each person**, choose a new effective date and enter that person's terms. Save the person or use the selected-person batch controls after reviewing each draft.

Saved project defaults are copied into new assignments as independent agreements. Changing the project or its defaults does not overwrite existing worker agreements. **Use project defaults in this draft** copies values for review; saving applies them from the chosen date.

Choose an explicit person reimbursement override to preserve it even when it currently matches the project default. Customer expense recovery is separate from worker reimbursement: an expense can reimburse the worker while charging the customer nothing.

## Effective dates and history

- A later agreement applies from its effective date. Earlier work retains the terms applicable to its work date.
- Current values remain visible when a future agreement is saved. Use **Review scheduled commercial terms** and **Work date** to inspect the selected rules for another date.
- Existing agreements on the same date are immutable. Use a later effective date for a change.
- Assignment dates cannot exclude retained time, expenses or reports. Ending an assignment preserves its dated financial history.
- Paid expenses, issued invoices and finalized settlements are protected from retrospective changes.

Workers see their own authorized pay and reimbursement information. Project managers and crew chiefs do not receive other people's compensation, customer rates or internal costs.
