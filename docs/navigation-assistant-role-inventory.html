What the assistant does

The implemented assistant runs in the browser without an LLM, model download, API key or remote NLP service. Unicode/accent normalization, English/Spanish/Portuguese synonym rules and Fuse.js fuzzy phrase matching turn a request such as “I wannt create a new project” into authorized task choices. The user chooses a result; it opens the existing URL, selects the correct view, reveals an existing menu/form and scrolls/focuses it. Required and optional fields, validation, review and save remain in the native form.

This fits the revised request better than a separate conversational form wizard: it preserves the app's required/optional fields, dependent selects, authorized record lists, financial state rules and existing audit/save flows. It can guide a user to a form; it does not submit, approve, delete, issue an invoice or record money from chat. Ranking scores measure text relevance and are not statistical probabilities.

Bare “invoice”, “report” and “pay” requests present alternatives. Unsupported, short irrelevant, action-only and negated input produce no launch. Arbitrary compound instructions, new workflows and open-ended semantic reasoning are outside this deterministic vocabulary. Record pickers use already-authorized page data; a missing record uses the correct register instead of guessing an identifier.

Role boundaries

Role / workforce profile Visible tasks Scope and conditions
Canonical Owner 112 Largest workspace: operations, project/client lifecycle, assignments, canonical team and mailbox administration, crew/supplier management, finance, billing, payments, accounting, documents, planning, audit.
Other Owner 102 Owner operational and financial workspaces remain; canonical team/mailbox controls stay hidden.
Finance Admin 56 Projects/clients, operational financial approval, commercial interpretation, rates/costs/settlements, invoicing/collections/accounting. No owner-only issuer/numbering, invoice void, crew/supplier/admin actions.
Project Manager 38 Scoped project assignments and planning, operational approvals/reports/documents, own time/expenses/pay/security. No commercial rates, tax, internal cost, other-worker pay or billing.
Worker 24 Own time, expenses, reports, pay/reimbursement state, expertise/security; crew recording only with active delegated crew-chief authority.
Supplier Coordinator 22 Own operational entry and supplier personnel/time/report workspace within the linked supplier. No internal finance, pay, team or company administration.
External Technician 19 Own operational entry and supplier operational report/security/help. No supplier personnel administration or internal finance.
Read-only Auditor 8 Finance/economic/ledger/accounting/audit read targets and personal notifications/account security. No business mutation commands.

Supplier coordinator and external technician are workforce profiles over the Worker role. Canonical Owner is a separately projected account condition. The server remains the authority: role visibility alone never guarantees permission for a particular project, person, delegated date, private file, financial state or session.
