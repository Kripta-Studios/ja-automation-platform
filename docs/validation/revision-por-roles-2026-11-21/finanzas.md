# Administración financiera

## Uso habitual

Revisar elementos facturables desde Inicio. Abrir Money para la posición por proyecto y moneda, Rates para condiciones comerciales, Invoices para borradores y emisión, y Payments para conciliación y cobros.

El cierre contable, la emisión definitiva y el cobro efectivo requieren evidencias independientes.

## Evidencia del 21 de noviembre

En la instancia aislada se abrió el asistente de facturas y se recorrieron vistas de facturación, contabilidad, pagos y configuración económica.
