## 8. Diagrama de Secuencia — Billing Period Close → Invoice Issue

```mermaid
sequenceDiagram
    participant Timer as Scheduled Job
    participant Engine as Billing Engine
    participant DB as SQLite
    participant Finance as Finance User
    participant PDF as PDF Generator

    Timer->>Engine: run-due (period close check)
    Engine->>DB: Check readiness for each billing stream
    
    alt Period READY
        Engine->>DB: Lock source time entries (billing_lock)
        Engine->>DB: Lock source expenses (billing_lock)
        Engine->>DB: Calculate labor subtotal (BigInt)
        Engine->>DB: Apply tax components (basis points)
        Engine->>DB: Create invoice draft
        Engine->>DB: Create invoice lines with snapshots
        Engine->>DB: Create period report
        Engine->>DB: Create outbox notification
        Engine-->>Finance: Notification: "Invoice draft ready"
    else Period INCOMPLETE
        Engine->>DB: List blockers (missing time, receipts, rates)
        Engine->>DB: Create outbox notification
        Engine-->>Finance: Notification: "Period blocked"
    end

    Finance->>DB: Review invoice draft
    Finance->>DB: Approve → mark Ready
    Finance->>DB: Issue invoice (transaction)
    
    Note over DB: Atomic issue transaction:<br/>1. Re-check authorization<br/>2. Allocate invoice number<br/>3. Snapshot all inputs<br/>4. Lock source rows<br/>5. Calculate final totals<br/>6. Mark Issued<br/>7. Commit

    DB->>PDF: Enqueue PDF generation
    PDF->>DB: Store PDF + SHA-256
    DB-->>Finance: Invoice issued + PDF ready
```

## 9. Diagrama de Secuencia — Worker Offline Sync

```mermaid
sequenceDiagram
    participant Worker as Worker Phone
    participant SW as Service Worker
    participant IDB as IndexedDB
    participant Server as Portal Server
    participant DB as SQLite

    Note over Worker: Plant with no connectivity

    Worker->>IDB: Create time draft (offline)
    Worker->>IDB: Create daily report draft
    Worker->>IDB: Queue receipt photo
    IDB-->>Worker: "3 items waiting to sync"

    Note over Worker: Connectivity restored

    SW->>Server: POST /api/sync (mutations array)
    
    loop For each mutation
        Server->>DB: Check baseVersion vs current version
        alt No conflict
            Server->>DB: Apply mutation
            Server-->>SW: {outcome: "accepted", version: N+1}
        else Version conflict
            Server-->>SW: {outcome: "conflict", fields: [...]}
            SW-->>Worker: "Server changed since your edit"
            Worker->>Worker: Review and resolve
        end
    end

    SW->>Server: Upload queued receipts
    Server->>DB: Store document with SHA-256
    SW-->>Worker: "Synced ✓"
```

## 12. Diagrama de Secuencia — Finance Time Economics Review

```mermaid
sequenceDiagram
    participant Finance as Finance Admin
    participant Portal as Portal UI
    participant DB as SQLite
    participant Engine as Billing Engine

    Finance->>Portal: Open Time Economics Review
    Portal->>DB: Query approved time entries for period
    DB-->>Portal: Time entries with worker/project
    
    loop For each time entry
        Portal->>Engine: Calculate billable minutes
        Note over Engine: Apply daily minimum rule<br/>max(actual, minimum)
        
        Portal->>DB: Get client labor rate (most specific)
        Note over Engine: chooseMostSpecificRate()<br/>assignment > worker > category > activity
        
        Portal->>Engine: Calculate client revenue candidate
        Note over Engine: hourlyRateForMinutes(rate, billableMinutes)
        
        Portal->>DB: Get worker compensation rule
        
        alt Percentage-based worker
            Portal->>Engine: percentageOfEligibleClientLabor()
            Note over Engine: eligibleLabor × percentageBps / 10000
        else Hourly worker
            Portal->>Engine: hourlyRateForMinutes(workerRate, approvedMinutes)
        end
        
        Portal->>DB: Get internal cost rule
        Portal->>Engine: Calculate internal cost
    end
    
    Portal-->>Finance: Display table:<br/>Actual → Approved → Billable →<br/>Client Revenue → Worker Comp →<br/>Internal Cost → Contribution
```
